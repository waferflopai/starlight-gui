Usage

How to Use

1. Fixed Sidebar

The sidebar stays fixed in place as you scroll. Click the ☰ button in the top‑left to slide it in or out. The main content pushes to make room.

2. Scroll to navigate

As you scroll down the page, the sidebar automatically highlights the section you're currently viewing. Click any sidebar link to jump directly to that section.

3. Cyberdeck Doors

Each input field has its own sliding door. Hover or focus on a field to slide its door open. Click the door to focus the input.

4. Customize

Override CSS variables in :root — --sl-accent, --sl-paper, --sl-ink, --sl-border, etc. The entire palette is adjustable.

📦 Installation

NPM (recommended)

npm install starlight-gui

CDN (quick start)

<link rel="stylesheet" href="https://unpkg.com/starlight-gui/dist/starlight.min.css" />
<script src="https://unpkg.com/starlight-gui/dist/starlight.min.js"></script>

🎨 Theming

Override these CSS variables in your :root or a parent selector:

--sl-paper: #f5f0e8; /* main background */
--sl-paper-white: #faf7f2; /* card / modal bg */
--sl-ink: #1e1c1a; /* primary text */
--sl-ink-soft: #3d3a36; /* secondary text */
--sl-ink-faded: #7a756e; /* muted text */
--sl-accent: #2a6b7c; /* primary accent */
--sl-accent-soft: #5a9aa8; /* hover / focus */
--sl-border: #ddd6cc; /* borders */
--sl-radius: 0px; /* corner radius */
--sl-font-sans: 'Inter', ...;
--sl-font-mono: 'JetBrains Mono', ...;

🧩 Components

Starlight ships with 14+ components out of the box. Every component is hackable — just add your own classes or override variables.

Buttons Cards Lists Badges Dropdowns Modals Popups Loaders Tabs Tables Code blocks Toasts Forms Cyberdeck Doors

📐 Layout & Utilities

Starlight includes a full suite of utility classes for layout, spacing, borders, text, and more — all prefixed with sl-. See the demo page for examples.

⚡ JavaScript API

Toast — slToast(icon, message, duration)

Modal — slOpenModal(id) · slCloseModal(id)

Popup — slOpenPopup(id) · slClosePopup(id)

Sidebar — Toggle with .sl-sidebar.open + body.sl-sidebar-open

Tabs — Auto‑bind via data-tab + id

Scrollspy — Auto‑highlights sidebar links based on scroll position.

📱 Responsive

Starlight adapts to any viewport. On mobile (<768px), the sidebar becomes a slide‑in overlay with a backdrop. All components reflow gracefully.

🔧 Hackability

Everything is built with plain CSS and vanilla JS. No build tools, no frameworks, no dependencies. You can copy, paste, and modify any part of the library. The source is ~15KB gzipped.
